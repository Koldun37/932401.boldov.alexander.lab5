# Лабораторная работа №5. DOM и взаимодействие с элементами страницы

Выполнил: Болдов Александр  
Вариант: 18 (Космический энтузиаст и астроном-любитель)

## Описание работы
Доработка веб-страницы астронома-любителя. Реализовано динамическое управление элементами через DOM API и сохранение пользовательского состояния в браузере с помощью `localStorage`.

## Что реализовано
- Поиск элементов на странице методами `getElementById`, `querySelector` и `querySelectorAll`.
- Проверка существования DOM-элементов перед обращением к их свойствам и методам с выводом предупреждений в консоль.
- Динамическая генерация карточек космических объектов (название, тип, яркость и кнопка удаления).
- Добавление новых объектов через поля ввода (или диалоговые окна при пустых полях) и удаление существующих карточек.
- Скрытие и показ секции «Объекты для наблюдения» по кнопке с обновлением текста и атрибутов.
- Переключение между темной и светлой темой оформления через изменение CSS-переменных и классов.
- Сохранение списка объектов, выбранной темы и видимости секции в `localStorage` с автоматическим восстановлением при перезагрузке страницы.

## Структура файлов
- `index.html` — разметка страницы
- `css/style.css` — стили, переменные тем и адаптивность
- `js/script.js` — работа с DOM и `localStorage` (ЛР №5)
- `images/` — изображения проекта
